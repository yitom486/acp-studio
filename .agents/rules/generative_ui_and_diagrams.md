# ACP Studio 生成式 UI 与出版级流程图调用准则

适用于所有连接至 ACP Studio 的 AI 助手与智能体。

---

## 核心原则：拒绝枯燥文本与“Mermaid 涂鸦”，全面拥抱富交互

ACP Studio 内置了专用的 5 位数端口 MCP 服务（`studio-ui`），为聊天窗口注入了原生交互式卡片与出版级矢量渲染器。所有智能体在回答时必须遵循以下准则：

---

### 一、图表规范：强制使用 `render_editorial_diagram`，禁用裸写 Mermaid

1. **绝对禁止事项**：
   - **禁止** 在聊天中输出粗糙、线段交叉错乱、样式单调的原始 Mermaid 代码块（如 ` ```mermaid ... ` ）。
2. **强制规范**：
   - 只要回答中涉及系统拓扑、调用链路、状态流转、选型决策或项目规划，**必须调用 `render_editorial_diagram` 工具**。
3. **图表类型与场景映射**：
   - **`architecture` (分层系统架构)**：展示微服务容器、网关接入层、核心服务层、数据存储分层拓扑与通信协议（HTTP/gRPC/WebSocket）。
   - **`sequence` (交互时序图)**：展示用户认证登录、跨服务 RPC、分布式事务两阶段提交等时序消息交互。
   - **`flowchart` (流程与状态机)**：展示业务执行阶段、订单/会话生命周期状态、异常重试逻辑。
   - **`quadrant` (四象限决策矩阵)**：展示技术选型（如架构方案的 收益 vs 复杂度 矩阵）、任务优先级评估。
   - **`timeline` (演进里程碑)**：展示项目推进计划、发布版本历程与核心任务达成情况。
4. **设计美学遵循**：
   - 贯彻 **1-Accent 聚焦原则**：全图保持黑白灰/中性极简底色，仅用一种鲜明强调色（如 `emerald`、`blue`、`indigo`）突出核心节点或主路径。

---

### 二、方案选择与状态汇报：优先调用 `show_interactive_card`

1. **方案选择与决策场景**：
   - 当向用户提供架构重构路径、库选型、部署环境选择时，调用 `cardType: "decision"`，支持用户一键点击选择并自动回传。
2. **任务与排查清单场景**：
   - 当向用户展示上线前门禁清单、配置排查步骤时，调用 `cardType: "checklist"`，供用户逐项勾选。
3. **指标与压测看板场景**：
   - 当向用户展示吞吐量、延迟、资源利用率或改动前后对比时，调用 `cardType: "metrics"`。

---

### 三、配置收集：优先调用 `prompt_form`

- 当需要用户提供数据库凭证、服务端口、环境变量或表单筛选参数时，**不得**要求用户在普通聊天框中逐行打字回复。
- **必须调用 `prompt_form`** 直接在对话流中生成整洁的交互式表单控件（支持 text/number/select/checkbox），等待用户一键提交。

---

### 四、前端组件原型预览：调用 `render_react_sandbox`

- 当为用户编写或演示独立的 React UI 组件、动态仪表盘原型时，调用 `render_react_sandbox`，前端将在隔离沙箱中即时挂载运行并展示交互预览。
